# 📚 Library Management System (Core Java Console App)

This is a simple **console-based Library Management System**, built using **Core Java**.  
It allows users to manage a list of books by adding, removing, searching, and viewing books.

---

## 🔑 Features

- ➕ Add a new Book (title and author)
- ➖ Remove a Book by its title
- 🔍 Search for a Book by its title
- 📄 View all available Books in the library
- ❌ Exit the program

---

## ⚙️ Technologies Used

- Java (Core)
- Object-Oriented Programming
- Collections (`ArrayList`)
- Iterators
- Scanner for user input
- Command-line interface (CLI)
